# How to Use Markdown for Writing and Documentation — A Beginner's Guide

Created in 2004 by John Gruber and Aaron Swartz, **Markdown** is a lightweight markup language designed to be easy to read and write using plain text formatting syntax. Today, it has become the universal standard for digital writing across GitHub, Reddit, Notion, Obsidian, Discord, static site generators, and modern publishing platforms.

Unlike traditional WYSIWYG word processors (such as Microsoft Word or Google Docs) that bury text inside proprietary XML files, Markdown keeps your words in clean, future-proof plain text.

In this beginner's guide, we review the essential Markdown syntax rules and show you how to start formatting documents with ease.

---

## 1. Headings

Headings are created using the hash symbol (`#`). The number of hashes indicates the heading level, from H1 to H6:

```markdown
# Level 1 Heading (Main Title)
## Level 2 Heading (Section Title)
### Level 3 Heading (Subsection)
#### Level 4 Heading
```

*Tip: For clean typography, leave a single blank space between the `#` symbols and your heading text.*

---

## 2. Text Styling (Emphasis)

Format individual words and phrases using asterisks or underscores:

```markdown
*Italicized text* or _Italicized text_
**Bold text** or __Bold text__
***Bold and italicized text***
~~Strikethrough text~~
```

---

## 3. Lists

Markdown supports both numbered (ordered) and bulleted (unordered) lists:

### Unordered Lists:
```markdown
- First item
- Second item
  - Nested sub-item (indent with 2 or 4 spaces)
- Third item
```

### Ordered Lists:
```markdown
1. Introduction
2. Methodology
3. Conclusion
```

*Tip: If you need to quickly add numbers to an existing plain text list, try our [Add Line Numbers](/tools/add-line-numbers) tool.*

---

## 4. Links and Images

Links and images share a similar, intuitive syntax:

### Hyperlinks:
```markdown
[Visit TextToolsHub](https://texttoolshub.com)
```

### Images:
```markdown
![Descriptive Alt Text](https://example.com/screenshot.png)
```

The exclamation mark (`!`) tells the parser to render the destination as an inline image rather than a clickable text link.

---

## 5. Blockquotes and Code Blocks

### Blockquotes:
Prefix paragraphs with the greater-than symbol (`>`) to format editorial citations or callouts:
```markdown
> "Simplicity is prerequisite for reliability."
> — Edsger W. Dijkstra
```

### Code Snippets:
Use backticks for inline code, or triple backticks for multiline code blocks:

```javascript
function greet(name) {
  return "Hello, " + name + "!";
}
```
